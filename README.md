# Fußballmanager – App-Updates

Hier stehen ausschließlich fertige, signierte Installations- und Update-Pakete für macOS auf Apple Silicon bereit. Der Quellcode wird separat privat verwaltet.

[Neueste Version herunterladen](https://github.com/LexxorHH/FM-Updates/releases/latest)

Die App prüft ab 0.2.29 beim Start auf neue Versionen. Eine angebotene Aktualisierung lässt sich im Startmenü installieren oder verschieben. Lokale Spielstände bleiben erhalten.

Einmalige Einrichtung: Das DMG öffnen und Fußballmanager in den Ordner Programme ziehen. Bisherige Versionen ohne Update-Funktion müssen einmal manuell ersetzt werden.

Die Update-Signatur wird vor der Installation geprüft. Die App ist derzeit ad hoc signiert; Apple-Notarisierung ist noch nicht eingerichtet.
